# Built-in Apps

pyComputer ships with six apps pre-installed under `root/usr/apps/`:

Calculator
  : A four-function calculator with keyboard input support.

IDE
  : A full TUI code editor with file tree, toolbar, syntax highlighting,
    and a run output panel.

Matrix
  : Matrix-style digital rain animation.

Notes
  : A plain-text note taker backed by the VFS.

Settings
  : Configure the system theme, set your username, and adjust other
    preferences.

Snake
  : Classic snake game with keyboard controls.
